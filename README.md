# finbardoyle.com

Website for Finbar Doyle, Irish musician. Plain static HTML and CSS, no build step.

- `index.html`: the page (About, Music, Gigs, Contact)
- `styles.css`: styles
- `assets/`: put photos here

Open `index.html` in a browser to preview. Sections still waiting on real content are marked with `TODO` comments.

Instagram: https://www.instagram.com/finbardoyle/
